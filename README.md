# AgentCamp — 신입이 물어볼 때마다, 팀의 "회의/슬랙 지식"으로 바로 답하고 바로 채점하는 OJT AI

신입 온보딩(OJT)에서 가장 비싼 건 "코드"가 아니라 **같은 질문에 같은 답을 반복하는 시간**입니다.

AgentCamp는 팀이 이미 갖고 있는 **회의 STT / Slack 대화**를 자동으로 "회사 룰·실수 패턴·프로세스"로 정리하고, 그 지식이 **질문 답변 → 제출 리뷰 → HR 대시보드**까지 즉시 연결되게 만드는 **OJT 운영 AI**입니다.

## 한 문장으로

**"회사에 있는 지식(회의/슬랙)이 신입의 질문에 답하고, 제출물을 같은 기준으로 리뷰/채점까지 해주는 시스템"**

---

## 30초 이해: AgentCamp가 바꾸는 업무의 흐름

### Before (현실)

- 신입: "이거 어떻게 해요?"
- 팀: Slack에 흩어진 답 / 사람마다 다른 기준 / 리드가 반복 대응
- 결과: 리뷰 편차 + 재작업 + 온보딩 지연

### After (AgentCamp)

- 팀의 회의/슬랙 텍스트 업로드
→ **회사 지식**(규칙/실수/프로세스)로 변환
→ 신입 질문은 **4명 Digital Twin(CEO/PM/FE/BE)** 중 적절한 역할이 답변
→ 제출물은 **원인/재현/재발방지/증거** 기준으로 자동 리뷰
→ HR/리드는 **적응도/리스크/질문량/완료율**을 한 화면에서 확인

---

## "이게 왜 새롭냐?" 핵심 차별성: 답변에서 끝나지 않는 폐루프

대부분의 AI 도구는 "답변"에서 끝납니다.

AgentCamp는 **업로드된 회사 지식이**
1) 답변의 근거로 **인용**되고
2) 리뷰의 기준으로 **반영**되고
3) 운영 지표로 **집계**되는
**OJT 운영 폐루프(Closed-loop)**를 만듭니다.

---

## 2분 데모에서 보여주는 장면(심사용)

1) Admin에서 회의 STT 업로드
2) "회사 규칙/실수 패턴" 3개가 자동 추출
3) New Hire가 질문 → 답변에 그 규칙이 **근거로 인용**
4) New Hire가 제출 → 리뷰에서도 같은 규칙이 **평가 기준으로 반영**
5) Dashboard에서 질문량/리스크/적응도 지표가 누적됨

---

## Offline-first (해커톤 데모에 최적)

- **API Key 없이도 100% 동작**: 데모가 절대 깨지지 않음
- Key가 있으면 Claude/OpenAI로 **품질 즉시 업그레이드**
- 실패 시 자동 폴백: "안 되면 멈추는 AI"가 아니라 "운영되는 AI"
