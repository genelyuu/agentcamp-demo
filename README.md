# AgentCamp — AI로 바꾸는 온보딩(OJT) 운영: “회사 지식 → 질문 → 리뷰 → 지표” 폐루프

## TL;DR (Judges)
**AgentCamp는 조직의 회의 ‘일상 텍스트’를 자동으로 "회사 룰·실수 패턴·프로세스"로 정리하고, 그 지식이 **질문 답변 → 제출 리뷰 → HR 대시보드**까지 즉시 연결되게 만드는 **OJT 운영 AI**입니다.

**“AI로 바꾸는 일과 업무”**
실제 업무에서 AI가 바꿔야 하는 건 “한 번 멋진 답변”이 아니라 **업무 운영의 비용 구조**입니다.  
온보딩(OJT)에서 가장 비싼 비용은 다음 두 가지로 귀결됩니다.

1) **반복 질문 비용:** 신입은 같은 질문을 반복하고, 리드/시니어는 같은 답을 반복합니다.  
2) **리뷰 품질 편차 비용:** 제출물 평가 기준이 사람마다 달라져 “재작업”이 발생합니다.

AgentCamp는 이 지점을 “문서화”가 아니라 **운영 시스템**으로 바꿉니다.

### “지식이 답변에서 끝나지 않고, 평가와 지표로 연결된다”
**회사 지식이 곧바로**
- 질문 답변의 근거로 인용되고,
- 제출 리뷰의 기준으로 반영되고,
- 운영 지표(리스크/적응도)로 집계됩니다.

# AI는 “대화”가 아니라 “업무 운영”을 바꿉니다.

---

- 팀의 회의/슬랙 텍스트 업로드
→ **회사 지식**(규칙/실수/프로세스)로 변환
→ 신입 질문은 **4명 Digital Twin(CEO/PM/FE/BE)** 중 적절한 역할이 답변
→ 제출물은 **원인/재현/재발방지/증거** 기준으로 자동 리뷰
→ HR/리드는 **적응도/리스크/질문량/완료율**을 한 화면에서 확인

---

## 제품 개요: 3모드로 완결되는 OJT 운영
### 1) Admin (회사 세팅/데이터 업로드)
- 회사/직무/루브릭(데모) 세팅
- 회의 STT/Slack 텍스트 업로드 → 규칙/실수/프로세스 지식 추출·저장
- **Active Knowledge Top-3**로 “운영에 쓰이는 지식”을 고정 표시

### 2) New Hire (OJT 실행)
- 오늘의 미션 수령(업무 컨텍스트 포함)
- 질문하기 → **Digital Twin 라우팅 + 근거(키워드/스코어) 노출 + 수동 override**
- 제출하기 → **구조 루브릭 점수/피드백 + 회사 지식 인용**

### 3) Dashboard (HR/리드 운영)
- 질문량/트윈 호출/재제출/완료 업무/적응도/리스크를 한 화면에서 확인
- “리스크 산정 규칙”을 명시해 지표의 의미를 고정

## 사업성: 
### 문제는 보편적이고 반복된다
- 스타트업/중소팀: 온보딩 문서가 없거나 최신성이 유지되지 않음
- 성장기 조직: 제품/프로세스 변화 속도가 빨라 “사람이 답변/리뷰를 따라가기 어려움”
- 원격·분산팀: Slack/회의 STT에 지식이 흩어져 있고, 온보딩은 개인 의존적

### AgentCamp의 ROI(정량화가 쉬움)
- 반복 질문 감소(리드/시니어 시간 절감)
- 리뷰 기준 표준화(재작업 감소)
- 리스크 조기 감지(근거 부족/재현 부재 등 패턴 추적)
- 온보딩 기간 단축(성과 도달 시간 단축)

### 비즈니스 모델(해커톤 이후 확장 가능)
- **B2B SaaS (per seat)**: 온보딩/교육 대상 인원 기준 과금
- **팀 플랜**: Slack/회의 연동 + 지식 거버넌스 + 감사 로그
- **Enterprise**: SSO, 권한관리, 개인정보/보안 정책, 모델 선택(사내 LLM/외부 LLM)

---

## Offline-first + LLM Enhanced
- **Offline(기본):** API Key 없이도 100% 동작(재현 가능, 데모 안정성 최우선)
- **LLM Enhanced(선택):** Key가 있으면 답변/추출/리뷰 품질 업그레이드
- **Fail-safe:** LLM 실패/지연 시 즉시 오프라인 모드로 폴백
